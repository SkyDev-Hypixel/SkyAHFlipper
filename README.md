# SkyAHFlipper

A Hypixel Skyblock auto-flipper macro designed specifically for Minecraft version **1.26.2**. Made with <3.

---

## ⚙️ Dependencies
To run this macro properly, you must install the following required mods:
*   **Fabric API**
*   **Coflnet**
